### Bug fixes

- After a force push to a repository's default branch, Semaphore reloads all of the repository's broadcasts from the branch's head commit. A broadcast whose file was only in the discarded history is removed, rather than being served until Semaphore restarts.
- After a repository's default branch is changed or renamed, the next push to the new default branch reloads all of the repository's broadcasts from it and removes those loaded from the old branch. Before, Semaphore served a second copy of each broadcast, and later pushes never updated or removed the copy from the old branch.

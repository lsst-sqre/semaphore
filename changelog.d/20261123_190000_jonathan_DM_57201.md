### New features

- If no installation of the GitHub App can see a repository listed in `SEMAPHORE_GITHUB_REPOS`, for example because its name is misspelled or the app isn't installed on it, Semaphore logs a warning at startup that lists those repositories.

### Bug fixes

- A suspended installation of the GitHub App no longer stops Semaphore from starting. Semaphore skips it with a warning, as it does an installation on an account that owns none of the repositories in `SEMAPHORE_GITHUB_REPOS`, and requests no access token for either.
- If GitHub fails or can't be reached while Semaphore authorizes an installation of the GitHub App or lists the installation's repositories at startup, Semaphore still starts and loads the other installations. It logs a warning and retries that installation in the background, as it does a repository that fails to load, and serves its broadcasts once it loads. The summary that Semaphore logs after loading broadcasts at startup reports the number of these installations as `failed_installation_count`.

### Bug fixes

- A push webhook that GitHub redelivers, or that arrives after a later push, no longer reverts a broadcast to older content or brings back a deleted broadcast. Semaphore now reads every broadcast file that a push adds, changes or removes at the default branch's current head commit, looked up once per push, and removes a broadcast only if its file doesn't exist at that commit. Before, the files of a push were read at different times, and a removed file's broadcast was deleted even if a later push had added the file back. Pushes to one repository are processed one at a time.

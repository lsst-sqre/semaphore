### Bug fixes

- The GitHub webhook endpoint returns a 401 response for a request with a missing or wrong signature, and a 400 response for a request with an unsupported content type or a payload without an `installation.id`, including a payload whose `installation` is null or that isn't a JSON object. It logs each of these as a warning. Before, they raised unhandled exceptions, which returned a 500 response and posted a Slack alert.
